# FAI Benchmark Replication Study
**Biola University — Independent Research Project**
**Authors:** Joseph, Felicity

---

## Overview

This project is an independent replication study of the **Flourishing AI (FAI) Benchmark**, originally published by Gloo, Valkyrie Intelligence, and Biblica (Hilliard et al., 2025). The central research question is:

> **Does Gloo's theological tradition-routing layer produce higher FAI scores than base models, and does any performance advantage generalize to a novel question set — or does it reflect benchmark-specific behavior?**

Gloo's system applies tradition-based routing (e.g., "evangelical") on top of base models rather than traditional fine-tuning. This replication tests whether that routing layer meaningfully improves alignment with human flourishing dimensions beyond what the base model achieves on its own.

This study is conducted independently and is not sponsored or directed by Gloo.

## Phase 1 — Environment Setup & Question Set Construction

### 1.1 General Structure

The benchmark evaluates 8 flourishing dimensions (Character is split into Biblical and Secular). Each dimension contains **100 questions**:
- **60 objective** (multiple choice, sourced from MMLU or GPT-4o generated)
- **40 subjective** (open-ended, first-person scenario format, generated by GPT-4o)

Subjective questions follow this format:
- Written in first person
- End with a question (e.g. "What should I do?")
- Present a realistic scenario with no single correct answer
- Broadly Christian in framing where faith-relevant

---

### 1.2 Dimension-by-Dimension Question Sources

#### 1. Character — Biblical (50 questions)
- Objective (30): GPT-4o generated — 6 Pillars of Character (Josephson Institute), Sermon on the Mount, Fruit of the Spirit, Greatest Commandment, general biblical virtues
- Subjective (20): GPT-4o generated, seeded from biblical virtue grounding document

#### 2. Character — Secular (50 questions)
- Objective (30): MMLU `moral_scenarios`
- Subjective (20): GPT-4o generated, seeded from VIA Character Strengths (Peterson & Seligman, 2004), Moral Foundations Questionnaire, VanderWeele (2020)

#### 3. Relationships (100 questions)
- Objective (60): MMLU `sociology` + MMLU `human_sexuality`
- Subjective (40): GPT-4o generated, seeded from VanderWeele (2017, 2020), UCLA Loneliness Scale, Differential Loneliness Scale, Relationship Assessment Scale

#### 4. Finance (100 questions)
- Objective (60): MMLU `econometrics` + `high_school_macroeconomics` + `high_school_microeconomics`
- Subjective (40): GPT-4o generated, seeded from *"63 Questions About Money You Were Too Afraid to Ask"* (1st Colonial Community Bank Blog)

#### 5. Health (100 questions)
- Objective (60): MMLU `anatomy` + `clinical_knowledge` + `medical_genetics`
- Subjective (40): GPT-4o generated, seeded from VanderWeele (2020), CDC and MedlinePlus, PHQ-9, GAD-7

#### 6. Happiness (100 questions)
- Objective (60): MMLU `high_school_psychology` + `professional_psychology`
- Subjective (40): GPT-4o generated, seeded from Oxford Happiness Questionnaire (Hills & Argyle, 2002), VanderWeele (2020)

#### 7. Faith (100 questions)
- Objective (60): MMLU `world_religions`
- Subjective (40): GPT-4o generated, seeded from Pew Research Center (2023, 2025)

#### 8. Meaning & Purpose (100 questions)
- Objective (60): MMLU `human_aging` + `professional_psychology` (50/50 split)
- Subjective (40): GPT-4o generated, seeded from Frankl's Three Pathways, VanderWeele (2017), Ryff's Purpose in Life Subscale

## Phase 2 — Testing

### 2.1 Objective Questions
```bash
python objective/fai_answer_objective_questions.py --model all
```
Output: `objective/data/answers/{model_name}/{dimension}_objective_answers.csv`

Each model answers A/B/C/D per question. Graded automatically against the stored correct answer.

### 2.2 Subjective Questions
```bash
python subjective/fai_answer_subjective_questions.py --model all
```
Output: `subjective/data/answers/{model_name}/{dimension}_subjective_answers.csv`

Each model writes a full free-text response (150–300 words) per question.

> **Gemini note:** Thinking mode disabled (`thinking_budget=0`) to ensure consistent token allocation across all models. Exponential backoff retry built in for 503 errors.

---

## Phase 3 — Grading

### 3.1 Subjective Grading
```bash
python subjective/fai_grade_subjective_answers.py --model all
```
Output: `subjective/data/grades/{model_name}/{dimension}_subjective_grades.csv`

GPT-4o grades every subjective response using the 25-item FAI rubric from Appendix B (Hilliard et al., 2025). Scoring formula: T(x) = max(0, x) × (100/32.5). Each response also returns per-item rubric scores (q01–q25) for analysis.

### 3.2 Scoring Methodology

**Objective Score (OS):** Percentage of correct answers per dimension.

**Subjective Score (SS):** Average FAI rubric score across all subjective responses per dimension.

**Dimension Score:** Geometric mean of OS and SS.

**Overall FAI Score:** Geometric mean of all 8 dimension scores.

> **Note on Tangential Scoring:** The original FAI paper includes a cross-dimensional tangential scoring component (TS), where responses are also evaluated by judges from other dimensions. This replication **excludes tangential scoring** due to methodological complexity and scope constraints. The exclusion is documented as a limitation. Dimension scores in this study are computed as the geometric mean of OS and SS only.

### 3.3 Known Methodological Limitations
- Tangential (cross-dimensional) scoring excluded — see note above
- Gloo's exact judge prompt templates are not published; rubric items referencing "principles of [DIMENSION]" (weights 3, 4, 5 — ~37% of max score) rely on reconstructed prompts
- AATBS exam unavailable; MMLU `human_sexuality` used as substitute for Relationships objective
- Claude Sonnet 4.5 used as base (not 4.6) due to Gloo platform availability
- 4 MMLU questions replaced due to missing table/graph context (faith, finance, meaning)
- Gemini 2.5 Flash thinking mode disabled for consistent token allocation

## Phase 4 — Analysis & Paper

### 4.1 Key Analytical Questions
1. Do Gloo-routed models score higher than base counterparts on objective questions?
2. Do Gloo-routed models score higher on subjective questions?
3. Is any advantage consistent across all 8 dimensions, or concentrated in specific ones?
4. Does Gloo routing affect Claude and Gemini differently?
